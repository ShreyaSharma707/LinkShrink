# LinkShrink Web

The client application for LinkShrink, a full-stack URL management tool with anonymous shortening, authentication, custom slugs, and URL analytics.

## Local development

Create a `.env` file with the API address:

```env
VITE_API_URL=http://localhost:3000
```

Install dependencies and start the development server:

```powershell
npm install
npm run dev
```

The development client runs at `http://localhost:5173`.
